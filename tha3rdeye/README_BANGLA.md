# 👁️ THA 3RD EYE · Red Key — প্রিমিয়াম আপগ্রেড গাইড

তোমার সাইট সম্পূর্ণ আপগ্রেড করে দেওয়া হয়েছে — নিচে সব পরিবর্তন, নতুন ফিচার, আর কিভাবে চালাবে তার ফুল গাইড।

---

## 📦 ফাইল স্ট্রাকচার

```
tha3rdeye/
├── server.js          ← ব্যাকএন্ড (Express) — সব বাগ ফিক্স + নতুন রুট
├── package.json       ← ডিপেন্ডেন্সি লিস্ট
└── public/
    └── index.html     ← ফ্রন্টএন্ড (নতুন প্রিমিয়াম UI + 3D অ্যানিমেশন)
```

⚠️ **গুরুত্বপূর্ণ:** `index.html` এখন `public/` ফোল্ডারের ভেতরে থাকতে হবে (আগে এটা root এ ছিল, যেটা একটা বাগ ছিল — নিচে দেখো)।

## 🚀 রান করার নিয়ম

```bash
npm install
npm start
```

তারপর ব্রাউজারে `http://localhost:3000` ওপেন করো।

Default Admin Login:
- Username: `admin`
- Password: `admin123`

**⚠️ প্রোডাকশনে যাওয়ার আগে অবশ্যই এই পাসওয়ার্ড চেঞ্জ করে নিও (`ensureAdminExists` ফাংশনে)।**

## 🐛 যেসব বাগ ফিক্স করা হয়েছে

1. **সার্ভার ক্র্যাশ বাগ (node-fetch)** — আগে `require('node-fetch')` করা ছিল কিন্তু `package.json` এ dependency হিসেবে ছিল না। ফ্রেশ সার্ভারে `npm install` করে রান করলেই সার্ভার ক্র্যাশ করতো। এখন Node.js এর বিল্ট-ইন `fetch()` ব্যবহার করা হচ্ছে (Node 18+), কোনো এক্সট্রা প্যাকেজ লাগবে না।

2. **"Cannot GET /" বাগ** — `express.static('public')` সেট করা ছিল কিন্তু `index.html` root এ ছিল, `public/` ফোল্ডারে না থাকায় ওয়েবসাইট ওপেনই হতো না। এখন `index.html` সঠিক জায়গায় (`public/index.html`) রাখা হয়েছে + একটা SPA fallback route যোগ করা হয়েছে যাতে যেকোনো পেজ থেকে রিফ্রেশ দিলেও সাইট লোড হয়।

3. **রিসেলার প্যানেলে Ban/Unban/Delete/Reset ছিল না** — আগে রিসেলার শুধু কী (key) তৈরি করতে পারতো, কিন্তু নিজের তৈরি করা কী ব্যান/আনব্যান/ডিলিট/রিসেট করতে পারতো না। এখন রিসেলার পুরোপুরি নিজের কী আর নিজের প্রোভাইডারের ক্লায়েন্টদের ম্যানেজ করতে পারবে (নিচে ডিটেইলস)।

4. **এক Gmail দিয়ে একাধিক অ্যাকাউন্ট তৈরি হওয়া** — আগে রেজিস্ট্রেশনে ইমেইল ইউনিকনেস চেক-ই ছিল না। এখন এক Gmail (dot আর +tag বাদ দিয়ে normalize করে) দিয়ে একটাই অ্যাকাউন্ট তৈরি হবে। যেমন `j.doe@gmail.com`, `jdoe@gmail.com`, আর `jdoe+promo@gmail.com` — এই তিনটাকেই সিস্টেম একই ইমেইল হিসেবে ধরবে।

5. **SID যতবার খুশি চেঞ্জ করা যেত** — এখন প্রতি ২৪ ঘণ্টায় ১ বার SID চেঞ্জ করা যাবে, সাথে লাইভ কাউন্টডাউন টাইমার (নিচে ডিটেইলস)।

## ✨ নতুন প্রিমিয়াম ফিচার (ফ্রন্টএন্ড)

### 👁️ প্রফেশনাল অ্যানিমেটেড আই লোগো
আগের ইমোজি (👁️) সরিয়ে একটা কাস্টম SVG লোগো বসানো হয়েছে যেটাতে:
- আইরিসে glow pulse অ্যানিমেশন
- চারপাশে ঘুরতে থাকা ২টা স্ক্যান রিং (ভিন্ন গতিতে, ভিন্ন দিকে)
- পিউপিল আস্তে আস্তে নড়াচড়া করে (যেন সত্যিই "দেখছে")
- মাঝে মাঝে হাইলাইট ব্লিংক

### 🖱️ মাউস মুভমেন্ট ইফেক্ট
- মাউস মুভ করলে একটা লাল স্পটলাইট/গ্লো কার্সরকে ফলো করে
- লোগো আর ড্যাশবোর্ডের হিরো কার্ডে মাউসের পজিশন অনুযায়ী রিয়েল 3D টিল্ট (rotateX/rotateY) হয়

### 🔊 ক্লিক সাউন্ড ইফেক্ট
- প্রতিটা বাটনে ক্লিক করলে একটা সিন্থেসাইজড "টিক" সাউন্ড বাজে (Web Audio API দিয়ে তৈরি — কোনো mp3 ফাইল ডাউনলোড করা লাগে না, তাই সাইট হালকা থাকে)
- সাথে আগে থেকে থাকা রিপল ইফেক্টও বজায় আছে

### 🌀 Crazy 3D ফিচার কারোসেল
লগইন আর রেজিস্টার পেজে একটা ঘূর্ণায়মান 3D কার্ড রিং (perspective + rotateY) — Security, Instant Delivery, HWID Lock, Reseller Network ইত্যাদি ফিচার হাইলাইট করে। মাউস হোভার করলে ঘোরা থেমে যায়।

### ⚡ গ্লিচ টেক্সট অ্যানিমেশন
মেইন হেডিং ("THA 3RD EYE", "Create Account") গুলোতে সাইবারপাংক-স্টাইল গ্লিচ ইফেক্ট।

### ⏱️ SID কুলডাউন — লাইভ কাউন্টডাউন
ড্যাশবোর্ডে "Update SID" এর পাশে এখন একটা চিপ দেখাবে:
- 🟡 কুলডাউনে থাকলে: লাইভ `HH:MM:SS` কাউন্টডাউন, বাটন ও ইনপুট ডিসেবল থাকবে
- 🟢 রেডি থাকলে: "Ready" দেখাবে, বাটন এনাবল

### 🔄 নতুন রিসেলার প্যানেল (৩টা ট্যাব)
1. **My Keys** — নিজের তৈরি সব কী দেখাবে + প্রতিটার পাশে **Ban / Unban / Reset / Delete** বাটন
   - Reset চাপলে কী আবার "available" হয়ে যাবে (যে ক্লায়েন্ট ব্যবহার করেছিল তার লাইসেন্সও রিসেট হবে)
2. **My Clients** — যারা নিজের প্রোভাইডারের কী রিডিম করেছে তাদের লিস্ট + **Ban / Unban / Reset SID / Delete** বাটন
   - রিসেলার শুধু নিজের প্রোভাইডারের ক্লায়েন্ট ম্যানেজ করতে পারবে, অন্য প্রোভাইডার/এডমিনের ইউজারে হাত দিতে পারবে না
3. **Create Key** — আগের মতোই কী জেনারেট করার ফর্ম

## 🔐 নতুন / আপডেট হওয়া API রুট (Backend)

| Method | Route | কাজ |
|---|---|---|
| POST | `/api/reseller/toggle-key-active` | নিজের কী ব্যান/আনব্যান |
| DELETE | `/api/reseller/delete-key` | নিজের কী ডিলিট |
| POST | `/api/reseller/reset-key` | ব্যবহৃত কী আবার available করা |
| GET | `/api/reseller/clients` | নিজের প্রোভাইডারের ক্লায়েন্ট লিস্ট |
| POST | `/api/reseller/toggle-client-active` | ক্লায়েন্ট ব্যান/আনব্যান |
| DELETE | `/api/reseller/delete-client` | ক্লায়েন্ট ডিলিট |
| POST | `/api/reseller/reset-client-sid` | ক্লায়েন্টের SID রিসেট |
| POST | `/api/client/update-sid` | এখন ২৪ঘণ্টা কুলডাউন সহ (আগে ছিল না) |
| POST | `/api/auth/register` | এখন এক-Gmail-এক-অ্যাকাউন্ট রুল সহ |

সব রুটেই আগের মতোই `Authorization: Bearer <token>` হেডার লাগবে, আর রিসেলার শুধু নিজের ডেটা এক্সেস করতে পারবে (ownership check করা আছে সার্ভার সাইডে)।

## ⚙️ Config যা তোমার নিজের বসাতে হবে

`server.js` এর উপরের দিকে:
```js
const BIN_ID = "..."; 
const MASTER_KEY = "...";
```
এগুলো তোমার নিজের JSONBin.io অ্যাকাউন্টের হলে ঠিক আছে; নতুন Bin বানালে এখানে বদলে দিও।

`SID_COOLDOWN_MS` চেঞ্জ করে চাইলে কুলডাউনের সময় বাড়ানো/কমানো যাবে (এখন `24 * 60 * 60 * 1000` = ২৪ ঘণ্টা)।
